# CAUSAL 2.0 - Independent Verification Task

Спасибо, что заглянули! Здесь лежат 5 синтетических тестовых векторов из моего исследовательского проекта. Мне нужен независимый взгляд со стороны.

## Что нужно сделать:
Взять 5 фикстур (папка `fixtures`), прочитать спецификацию (прилагается отдельно), написать свой мини-скрипт на Python или JS и **независимо** пересчитать для них байты, хэши и подписи (Ed25519).

## Список кейсов и что они проверяют:
*   `3Z-V-A-01` — Успешный кейс (LOCAL_BYTES_MATCH). Нужно пересчитать canonical, frame, SHA256 и проверить подпись.
*   `3Z-V-B-13` — Число больше 2^53-1. Ожидается SCHEMA_REJECT (не парсинг!).
*   `3Z-V-B-16` — Непарный Unicode surrogate. Ожидается PARSE_REJECT.
*   `3Z-V-C-07` — Неверная длина/структура фрейма. Ожидается FRAME_REJECT.
*   `3Z-V-C-12` — Подмена SHA256(payload) вместо SHA256(frame). Ожидается DIGEST_REJECT.

## Файлы:
*   `fixtures/` — Входные данные.
*   `reference/` — Ожидаемые результаты (то, что должен подтвердить ваш скрипт).
